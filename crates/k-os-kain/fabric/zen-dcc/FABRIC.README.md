# Zen DCC Fabric Workspace

This workspace is the first embedded Fabric lane for the native Zen host.

Current scope:

- Python project seeding for operator-facing defaults
- Kain bootstrap projection for a native session summary
- JSON report and event emission for the Zen Fabric panel

This workspace is intentionally small so Zen can embed Fabric as a first-class subsystem before expanding into ingest, bake, topology, publish, and tensor lanes.
