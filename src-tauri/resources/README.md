# K_OS Bundled Resources

This directory contains factory default assets shipped with K_OS.

**Read-only** - users cannot modify these files.

## Structure

- `KProjects/` - Template projects
- `KBrushes/` - Default brush presets
- `KMatcaps/` - Matcap materials
- `KAlphas/` - Alpha stamp textures
- `KMaterials/` - Material presets
- `KMeshes/` - IMM/Insert mesh primitives

## User Data

User-created assets are saved to:
`Documents/K_OS/` (read/write)
